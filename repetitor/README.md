# Репетитор — сайт с тестами (GitHub Pages)

Статическая копия страницы «Репетитор»: открывается на любом устройстве **без входа в Claude**.

- `tests/*.json` — тесты в формате скилла `repetitor` (источник).
- `config.json` — имена детей (`k5`, `k8`).
- `tools/build_site.py` — собирает сайт в `../docs/` (страница + `data/index.json` + `data/tests/<id>.json`).
- `tools/tutor.html` — копия шаблона страницы из скилла.

```
python3 repetitor/tools/build_site.py
git add docs repetitor && git commit -m "repetitor: новый тест" && git push
```

GitHub Pages: Settings → Pages → Source «Deploy from a branch», ветка `main`, папка `/docs`.

## Ссылки для детей

- Список тестов ребёнка: `https://<user>.github.io/<repo>/?kid=k8`
- Сразу открыть тест: `https://<user>.github.io/<repo>/?kid=k8&test=<id>`

## Как возвращаются результаты

На сайте нет базы: ответы хранятся в браузере ребёнка. В конце теста кнопки
«Поделиться» / WhatsApp / Telegram / «Скопировать результат» отправляют текст
`РЕПЕТИТОР-РЕЗУЛЬТАТ …` родителю. Родитель вставляет его в чат с Claude —
результат попадает в статистику страницы «Репетитор» (артефакт).

Разбор фото решения и «Объясни по-другому» на сайте недоступны (нужен Claude);
вместо этого ребёнок фотографирует решение и отправляет родителю.
