Степени под корнем и модуль

Три правила из §8, которые нужно держать в голове. Прочитай, потом пройди тест на скорость.

1Главное правило: $\sqrt{x^2} = |x|$

Знак $\sqrt{\ }$ всегда даёт число больше или равно нулю. Поэтому из квадрата получается не само $x$, а его модуль:

$$\sqrt{x^2} = |x| \qquad\text{для любого } x$$
$x$$x^2$$\sqrt{x^2}$$|x|$
$5$$25$$5$$5$
$0$$0$$0$$0$
$-5$$25$$5$$5$
Ловушка. $\sqrt{(-7)^2}$ — это не $-7$ и не $\pm 7$, а просто $7$. Знак $\pm$ появляется только при решении уравнения $x^2 = 49$; сам корень — одно число.

2Чётная степень под корнем: показатель делим на 2

Любую чётную степень можно записать как квадрат: $x^{8} = (x^4)^2$, $x^{14} = (x^7)^2$. Тогда работает правило 1:

$$\sqrt{x^{2n}} = \sqrt{(x^n)^2} = |x^n|$$

Дальше два случая, смотри на показатель после деления:

ПримерДелим показатель на 2Степень после деленияОтвет
$\sqrt{a^{8}}$$|a^4|$4 — чётная, $a^4 \ge 0$ всегда$a^4$
$\sqrt{y^{12}}$$|y^6|$6 — чётная$y^6$
$\sqrt{b^{6}}$$|b^3|$3 — нечётная, знак зависит от $b$$|b^3|$ — нужно знать знак $b$
Ловушка. $\sqrt{y^4} = y^2$, а не $y$. Делим на 2, а не на 4: $y^4 = (y^2)^2$.
Проверка подстановкой. Возьми $y = 2$: $\sqrt{2^4} = \sqrt{16} = 4 = 2^2$. Значит $y^2$, а не $y$.

3Если после деления степень нечётная — смотри на знак переменной

Нечётная степень сохраняет знак числа: $(-2)^3 = -8$, $(-1)^5 = -1$. Поэтому $|x^n|$ при нечётном $n$ раскрывается по-разному:

$$\sqrt{x^{6}} = |x^3| = \begin{cases} x^3, & \text{если } x \ge 0 \\ -x^3, & \text{если } x < 0 \end{cases}$$

Почему минус? При $x < 0$ число $x^3$ отрицательное, а корень отрицательным быть не может. Минус перед отрицательным числом делает его положительным: $-(-8) = 8$.

ЗаданиеОтветПроверка числом
$\sqrt{x^{6}}$, $x > 0$$x^3$$x=2$: $\sqrt{64} = 8 = 2^3$ ✓
$\sqrt{x^{6}}$, $x < 0$$-x^3$$x=-2$: $\sqrt{64} = 8$; $x^3 = -8$, значит $-x^3 = 8$ ✓
$\sqrt{a^{10}}$, $a < 0$$-a^5$$a=-1$: $\sqrt{1} = 1$; $a^5 = -1$, значит $-a^5 = 1$ ✓
$\sqrt{c^{8}}$, $c < 0$$c^4$4 — чётная, минус не нужен: $c=-1$: $\sqrt{1} = 1 = (-1)^4$ ✓
Универсальная проверка. Сомневаешься — подставь $x = -1$ (или $-2$) в условие и в свой ответ. Числа должны совпасть. Это занимает 10 секунд и ловит любую ошибку со знаком.

4Когда можно пользоваться свойствами корней

Свойства работают только если каждый корень в формуле существует, то есть под ним число $\ge 0$. И на ноль делить нельзя.

СвойствоУсловиеПочему именно такое
$\sqrt{ab} = \sqrt{a}\cdot\sqrt{b}$$a \ge 0,\ b \ge 0$справа стоят $\sqrt a$ и $\sqrt b$ — оба должны существовать
$\sqrt{\dfrac{a}{b}} = \dfrac{\sqrt a}{\sqrt b}$$a \ge 0,\ b > 0$для $b$ знак строгий: $b$ в знаменателе, а на 0 делить нельзя
$\sqrt{x^2} = |x|$любой $x$$x^2$ никогда не отрицательно, ограничений нет
Ловушка. $\sqrt{(-4)\cdot(-9)}$ — корень есть, потому что $(-4)(-9) = 36 > 0$. Но разложить его как $\sqrt{-4}\cdot\sqrt{-9}$ нельзя: корней из отрицательных чисел не существует. Правильно: сначала перемножить, $\sqrt{36} = 6$.

Запомни

  • $\sqrt{x^2} = |x|$ — ответ никогда не отрицательный.
  • Чётная степень под корнем: показатель делим на 2.
  • Получилась чётная степень — модуль не нужен. Нечётная — смотри на знак: при $x<0$ ставь минус.
  • Проверяй подстановкой $x = -1$.
  • $\sqrt{ab}=\sqrt a\sqrt b$ при $a\ge0,\ b\ge0$; $\sqrt{a/b}$ — ещё и $b \ne 0$, то есть $b>0$.
